Rediseña y mejora el prototipo actual de ALLPACA, un marketplace premium de ropa de paca/segunda mano. Mantén la identidad elegante, minimalista y principalmente monocromática del diseño existente, pero haz que la experiencia se sienta más moderna, atractiva y tecnológica sin parecer una tienda genérica, una feria o una página excesivamente colorida.

IMPORTANTE: trabaja sobre el diseño existente y conserva su identidad visual general. No reemplaces completamente el concepto actual.

## 1. INTRO / HERO ANIMADO

Actualmente existe una pantalla completamente negra con el nombre "ALLPACA" en letras blancas.

Quiero convertir esta pantalla en una introducción animada de la página:

* Fondo negro.
* "ALLPACA" centrado horizontal y verticalmente.
* Tipografía elegante, moderna y premium.
* El nombre debe aparecer inicialmente como el elemento principal de la página.
* Después de un pequeño retraso, el texto "ALLPACA" debe desplazarse y reducirse suavemente hasta convertirse en el logotipo/nombre ubicado en la esquina superior izquierda del menú principal.
* Utilizar una transición suave tipo Smart Animate.
* La sensación debe ser de una introducción cinematográfica y premium, no de una animación exagerada.
* Al terminar la animación debe aparecer el contenido principal de la página.
* La navegación principal debe quedar fija en la parte superior.

El objetivo es que el usuario sienta que entra a ALLPACA y que el nombre de la marca se transforma naturalmente en el encabezado de la página.

## 2. NAVEGACIÓN PRINCIPAL

En la parte superior debe existir un menú principal limpio y horizontal:

ALLPACA | DIRECTORIO | COMUNIDADES | DASHBOARD

A la derecha:

* icono de búsqueda
* selector de moneda/país
* icono de usuario
* carrito

El selector de moneda/país actualmente existente debe desaparecer de esta navegación y dejar espacio para una navegación más limpia.

Mantener mucho espacio en blanco y una jerarquía visual clara.

## 3. SEGUNDO MENÚ / CATEGORÍAS

Actualmente existe un menú dentro de la sección negra con categorías como:

TOPS
BOTTOMS
ACCESSORIES

Quiero conservar la idea, pero convertirlo en una navegación secundaria de categorías de ropa.

Proponer y mostrar categorías como:

TOPS
BOTTOMS
OUTERWEAR
DRESSES
ACCESSORIES

El segundo menú debe ser discreto y elegante, visualmente subordinado al menú principal.

No debe competir con DIRECTORIO, COMUNIDADES y DASHBOARD.

Puede funcionar como una barra de categorías horizontal debajo del menú principal o integrada de manera elegante en la transición entre el hero y el contenido.

## 4. USUARIO ÚNICO

Eliminar la separación conceptual entre "Explorador" y "Dealer".

ALLPACA debe tener un único tipo de usuario.

El mismo usuario puede:

* comprar productos
* publicar productos
* vender ropa
* administrar sus publicaciones
* consultar sus ventas
* consultar sus compras
* revisar estadísticas

Modificar especialmente la experiencia de LOGIN para que exista un único tipo de cuenta.

Después del inicio de sesión, el usuario tendrá acceso tanto a funciones de comprador como de vendedor.

El DASHBOARD debe mostrar información relevante de ambas actividades, eso incluye agregar la sección de compras no únicamente ventas.

## 5. DIRECTORIO

DIRECTORIO debe representar el contenido principal del marketplace.

Debe mostrar productos nuevos, destacados o populares.

La interfaz debe sentirse como una plataforma de descubrimiento de moda, no como un catálogo tradicional.

Mantener tarjetas de producto limpias y modernas.

Agregar un pequeño tag o etiqueta visual con la ciudad, por ejemplo:

"CDMX"
"CUERNAVACA"
"PUEBLA"
"GUADALAJARA"

La etiqueta de ciudad debe integrarse elegantemente en la tarjeta y no dominar la imagen.

## 6. "RECOMENDADOS PARA TI"

La sección actualmente llamada:

"RECOMENDADOS PARA TI"

debe mantenerse.

Reducir el espacio vertical innecesario entre el título y los productos.

Los productos deben aparecer SIEMPRE en una sola fila.

NO crear una segunda fila cuando la pantalla sea más pequeña.

Convertir esta sección en un carrusel horizontal.

Debe poder desplazarse lateralmente y sentirse como un carrusel continuo/infinito.

Agregar más productos de ejemplo para que el carrusel se vea completo y realista.

La intención es que el usuario pueda descubrir continuamente prendas sin que la sección ocupe demasiado espacio vertical.

Evitar tarjetas demasiado grandes.

## 7. BÚSQUEDA

Actualmente existe una barra de búsqueda muy grande entre la pantalla negra y "RECOMENDADOS PARA TI".

Reducir considerablemente su tamaño.

Debe seguir siendo claramente visible y fácil de utilizar, pero debe ocupar menos espacio.

Diseñarla como una barra de búsqueda premium y minimalista, con:

* icono de búsqueda
* placeholder como "Buscar prendas, marcas o estilos..."
* bordes sutiles
* proporciones elegantes
* suficiente espacio para escribir

Debe funcionar visualmente como transición entre el hero y el contenido.

## 8. PALETA DE COLORES

La estética actual es completamente blanco y negro y se siente demasiado sobria.

NO quiero abandonar el concepto monocromático.

Mantener:

* negro
* blanco
* grises

pero introducir un color de acento muy sutil y sofisticado.

El color debe utilizarse únicamente para pequeños detalles como:

* estados hover
* botones importantes
* etiquetas
* pequeños indicadores
* elementos interactivos

No utilizar colores brillantes, neón, degradados llamativos ni múltiples colores.

La estética debe seguir siendo conservadora, elegante y premium.

Explorar un acento muy discreto como:

* verde oliva oscuro
* verde salvia profundo
* beige/taupe
* borgoña muy oscuro

Elegir solamente UNO de estos como color de acento y utilizarlo con moderación.

El resultado debe sentirse como una plataforma de moda contemporánea y premium.

## 9. ESTÉTICA GENERAL

ALLPACA debe transmitir:

* premium
* moda
* minimalismo
* confianza
* curaduría
* modernidad
* economía circular
* ropa de segunda mano de buena calidad

Evitar:

* apariencia de tienda genérica
* exceso de colores
* exceso de sombras
* botones gigantes
* demasiados bordes
* demasiados elementos visuales
* apariencia de marketplace barato
* estética de "feria"
* diseño excesivamente corporativo

Utilizar:

* mucho espacio negativo, pero sin desperdiciar espacio
* tipografía elegante
* jerarquía clara
* fotografías grandes y limpias
* microinteracciones sutiles
* bordes y separadores muy discretos
* animaciones suaves

## 10. RESPONSIVE

El diseño debe adaptarse a diferentes tamaños de pantalla.

Especialmente importante:

La sección "RECOMENDADOS PARA TI" debe permanecer en UNA SOLA FILA independientemente del ancho disponible.

Si no caben todos los productos, deben permanecer fuera de pantalla y poder descubrirse mediante el carrusel horizontal.

NO convertirlos en grid de dos o más filas.

## 11. EXPERIENCIA FINAL

La experiencia debe sentirse así:

1. Pantalla negra.
2. "ALLPACA" aparece en blanco en el centro.
3. El usuario permanece unos instantes en la introducción.
4. "ALLPACA" se desplaza suavemente hacia la esquina superior izquierda y se convierte en el logotipo del menú.
5. Aparece la navegación principal.
6. Aparece el contenido del Directorio.
7. El usuario puede buscar productos.
8. Puede explorar categorías.
9. Puede desplazarse horizontalmente por "RECOMENDADOS PARA TI".
10. Puede entrar a Comunidades y descubrir productos asociados a diferentes colectivos/categorías.
11. Puede utilizar el Dashboard para administrar tanto sus compras como sus ventas.

El resultado debe parecer una plataforma real de moda que podría convertirse posteriormente en una aplicación web desarrollada con HTML, CSS y Angular.

Prioriza una experiencia visual premium, coherente y funcional sobre agregar muchos elementos.
